# NCM to Audio Decoder & Metadata Enricher

一个轻量、轻快的 NetEase Cloud Music (`.ncm`) 解码与元数据自动补全工具。

仅使用 Python 标准库实现，无需安装任何第三方库，开箱即用。

---

## 💡 元数据获取路径

本项目采用以下路径获取并补全音频文件的元数据：

1. **提取加密 Key**：
   - **NCM 密文文件**：解密 NCM 文件内的元数据块，获得 `163 key`。
   - **已解密的非 VIP 歌曲**：读取音频文件内嵌的 `DESCRIPTION` (FLAC) 或 `COMMENT` (MP3) 字段并解密，获得 `163 key`。
2. **定位歌曲与专辑 ID**：从 `163 key` 中解析出网易云官方的歌曲 ID 与专辑 ID。
3. **接口补全元数据**：通过网易云接口，精准匹配并补全以下音频字段：
   - **标题与专辑**：歌曲名、专辑名
   - **独立多艺人**：歌手（Artist）、专辑歌手（Album Artist）
   - **音轨与碟片**：音轨号（Track Number）、音轨总数（Track Total）、碟片号（Disc Number）、碟片总数（Disc Total）
   - **唱片出版**：发行日期（Date）、唱片公司（Organization）
   - **歌词与画质**：自动合并双语歌词（过滤纯时间轴空行）、拉取无裁剪的高清专辑封面图

---

## ✨ 核心特性

* **🚀 极速解密**：使用大整数位运算进行底层异或解密。40MB 无损音乐解码仅需 **0.05 秒**（比传统逐字节循环异或提速约 80 - 100 倍）。
* **👥 规范的多艺人写入**：
  - **FLAC 文件**：写入多行独立的 `ARTIST` 和 `ALBUMARTIST` 字段。
  - **MP3 文件**：在标准 ID3v2.4 元数据中为每位艺人独立写入 `TPE1`（歌手）帧与 `TPE2`（专辑歌手）帧。
  - 完美契合 AIMP、Mp3tag 等专业播放器和管理软件的分类检索。
* **🔒 智能限流与缓存**：
  - 内存缓存网络请求结果与封面图片。相同专辑仅下载一次封面，大幅提升批量处理速度。
  - 仅在网络请求时引入 `0.3s` 安全延迟，防范 IP 被官方接口限流或屏蔽。
* **🛡️ 强大的容错能力**：
  - **指数退避重试**：网络请求失败时自动进行最多 3 次排队重试，等待时间随重试次数翻倍。
  - **失败断点续扫**：无版权或转换失败的文件自动记录至同目录的 `failed_list.txt`，二次运行时可设定仅处理失败列表。

## 🛠️ 配置与使用

### 配置文件
编辑同目录下的 `ncm_to_audio_config.toml`，可配置扫描路径（`input_dirs`）、写出路径（`output_dir`）、是否递归（`recursive`）及处理模式。

### 运行方式
直接运行脚本，根据终端提示选择模式：
* **模式 1**：**仅转换 NCM**。解码 NCM 文件为原始 `.flac`/`.mp3` 格式，保留原有的低清封面和基础元数据。
* **模式 2**：**转换并补充元数据**。会自动执行 API 网络匹配，下载高清封面、合并双语歌词并补全完整的音轨、日期等元数据。
